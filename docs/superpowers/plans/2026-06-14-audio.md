# Audio System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a cozy-acoustic audio layer — looping music + 9 targeted SFX — with separate Music and SFX toggles in Settings, sourced from Pixabay and committed to the repo.

**Architecture:** A new `js/audio.js` module wraps `HTMLAudioElement` (no Web Audio API). Audio files live in `audio/music/` and `audio/sfx/`. SFX uses `cloneNode().play()` so rapid actions can overlap. Music starts on the first user gesture (autoplay policy). Settings toggles flip `state.settings.musicOn` / `sfxOn`; the audio module reads those live, so nothing needs caching.

**Tech Stack:** Zero-build vanilla JS (`window.Garden` namespace, plain script tags, works on `file://`), `HTMLAudioElement`, localStorage persistence. Pixabay CDN for source files (royalty-free, no attribution required).

**Spec:** `docs/superpowers/specs/2026-06-14-audio-design.md`

**Testing:** No test runner exists in this project (intentional — zero-build). Tasks 2–7 are browser/console verifiable; Task 1 verifies via file presence + filesize. Open `index.html` in a browser and use DevTools.

**Conventions you must follow:**
- Files attach to `window.Garden` via IIFE: `(function (Garden) { ... })(window.Garden);`
- Defensive call site pattern: `Garden.audio && Garden.audio.playSfx("name");` (matches the existing `Garden.fx &&` style)
- Never bump `storage.js` VERSION — version mismatch wipes saves by design. New fields are defensively defaulted in `main.js` start instead.
- After any state change: `Garden.storage.save(currentState); renderAll(currentState);`

### Task 2: Create `js/audio.js` module

**Files:**
- Create: `js/audio.js`
- Modify: `index.html` (add script tag after `js/fx.js`)

- [ ] **Step 1: Create the module**

```js
window.Garden = window.Garden || {};

(function (Garden) {
  const SFX_NAMES = [
    "plant", "water", "sun", "harvest",
    "level-up", "quest-complete", "chest", "rare-sparkle", "ui-click",
  ];
  const MUSIC_PATH = "audio/music/garden-theme.mp3";
  const SFX_VOLUME = 0.6;
  const MUSIC_VOLUME = 0.4;

  // Template elements — never played directly; cloned per shot so SFX can overlap.
  const sfxTemplates = {};
  let musicEl = null;
  let stateRef = null;
  let preloaded = false;

  function preload() {
    if (preloaded) return; // idempotent
    SFX_NAMES.forEach(name => {
      const a = new Audio("audio/sfx/" + name + ".mp3");
      a.preload = "auto";
      a.volume = SFX_VOLUME;
      sfxTemplates[name] = a;
    });
    musicEl = new Audio(MUSIC_PATH);
    musicEl.loop = true;
    musicEl.volume = MUSIC_VOLUME;
    musicEl.preload = "auto";
    preloaded = true;
  }

  // Called once at boot from main.js so playSfx/startMusic can read live settings.
  function _setState(state) { stateRef = state; }

  function playSfx(name) {
    if (!stateRef || !stateRef.settings || !stateRef.settings.sfxOn) return;
    const tmpl = sfxTemplates[name];
    if (!tmpl) return;
    try {
      const clone = tmpl.cloneNode();
      clone.volume = SFX_VOLUME;
      // .play() returns a Promise that rejects if autoplay is blocked; swallow it.
      const p = clone.play();
      if (p && typeof p.catch === "function") p.catch(() => {});
    } catch (_) { /* no-op */ }
  }

  function startMusic() {
    if (!stateRef || !stateRef.settings || !stateRef.settings.musicOn) return;
    if (!musicEl) return;
    try {
      const p = musicEl.play();
      if (p && typeof p.catch === "function") p.catch(() => {});
    } catch (_) { /* no-op */ }
  }

  function stopMusic() {
    if (!musicEl) return;
    musicEl.pause();
  }

  function setMusicEnabled(on) {
    if (on) startMusic();
    else stopMusic();
  }

  // SFX has no persistent element — playSfx reads stateRef.settings.sfxOn live —
  // so this is a no-op kept for API symmetry with setMusicEnabled.
  function setSfxEnabled(_on) {}

  Garden.audio = {
    preload, playSfx, startMusic, stopMusic,
    setMusicEnabled, setSfxEnabled, _setState,
  };
})(window.Garden);
```

Resulting order: `... fx.js → audio.js → render.js → main.js`. Render and main must see `Garden.audio`, so this order matters.
